# PocketBridge (راهنمای فارسی)

**PocketBridge** یک پل بلوتوث کم‌مصرف (BLE) متن‌باز و رمزنگاری‌شده سرتاسری (E2EE) است که امکان مدیریت تماس‌ها، پیامک‌ها، مخاطبین و تاریخچه تماس گوشی اندرویدی (Android 12+) را روی آیفون (iOS 17+) بدون نیاز به سرور ابری فراهم می‌کند.

## تنظیمات پیشنهادی باتری در اندروید
- بهینه‌سازی باتری را برای PocketBridge غیرفعال کنید.
- در گوشی‌های شیائومی (HyperOS/MIUI)، گزینه **Autostart** را فعال کرده و برنامه را در صفحه برنامه‌های اخیر قفل کنید.
- در گوشی‌های سامسونگ، برنامه را از فهرست **Sleeping Apps** خارج کنید.
